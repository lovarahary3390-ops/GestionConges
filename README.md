# Gestion des congés

## Description
Application web de gestion des demandes de congé des employés avec un workflow de validation.

## Technologies utilisées
- Backend : Python, Django, Django REST Framework
- Frontend : React, Vite
- Base de données : à préciser selon la configuration du projet

## Fonctionnalités
- Authentification des utilisateurs
- Gestion des employés
- Création et consultation des demandes de congé
- Validation des demandes selon un workflow
